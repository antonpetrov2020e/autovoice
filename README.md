# 🎙️ Voice Memo Auto Transcriber

Автоматическая транскрипция голосовых заметок из приложения "Диктофон" (Voice Memos) на Mac с сохранением в Obsidian.

## 📋 Описание

Это решение автоматически:
1. **Отслеживает** появление новых записей в Voice Memos
2. **Транскрибирует** их с помощью Groq Whisper (бесплатно)
3. **Обрабатывает большие файлы**: автоматически разделяет записи > 20 MB на части
4. **Улучшает текст**: исправляет ошибки, расставляет пунктуацию, форматирует
5. **Генерирует осмысленные заголовки** на основе содержания
6. **Использует пользовательский словарь** для точной транскрипции имен и терминов
7. **Сохраняет** красиво оформленные заметки в Obsidian

Больше не нужно вручную искать записи и отправлять на расшифровку!

### ✨ Новые возможности

- **Умные заголовки**: Вместо "2025-11-19 - Voice Memo" создаются осмысленные названия типа "15 ноября, суббота" или "Встреча с психологом"
- **Правильная типографика**: Автоматические «ёлочки» для кавычек и длинное тире (—)
- **Пользовательский словарь**: Система запоминает сложные имена, термины и названия для улучшения качества
- **Автоматическое извлечение задач**: Система анализирует дневниковые записи и создает единый файл с задачами и напоминаниями, организованный по месяцам и дням
- **Глубинный самоанализ**: Автоматический анализ дневника по 4 блокам (благодарность, эмоции, смысл жизни, личностный рост) для работы с внутренним миром

## 🔍 Где хранятся записи Voice Memos?

Voice Memos на Mac сохраняет записи в:
```
~/Library/Application Support/com.apple.voicememos/Recordings/
```

**Важно:** Путь, который вы видели (`/tmp/.com.apple.uikit.itemprovider.temporary...`) — это временная папка, используемая только при передаче данных между приложениями. Реальные записи хранятся в папке выше.

## 🚀 Установка

### 1. Клонируйте репозиторий

```bash
git clone <url-репозитория>
cd autovoice
```

### 2. Установите системные зависимости

Для обработки больших аудио файлов требуется ffmpeg:

**macOS:**
```bash
brew install ffmpeg
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install ffmpeg
```

### 3. Установите Python зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте конфигурацию

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:

```bash
# Groq API ключ (БЕСПЛАТНО на https://console.groq.com/keys)
# Используется для транскрипции аудио (Whisper)
GROQ_API_KEY=your_groq_api_key_here

# OpenRouter API ключ (https://openrouter.ai/keys)
# Используется для улучшения текста и извлечения задач
OPENROUTER_API_KEY=your_openrouter_api_key_here

# Модель для транскрипции (Whisper Large v3 Turbo - быстрая и точная)
TRANSCRIPTION_MODEL=whisper-large-v3-turbo

# Модель для улучшения текста (рекомендуется gpt-4o-mini)
TEXT_IMPROVEMENT_MODEL=openai/gpt-4o-mini

# Модель для извлечения задач
TASK_EXTRACTION_MODEL=openai/gpt-4o-mini

# Путь к папке с записями Voice Memos
VOICE_MEMOS_PATH=/Users/viktorivanov/Library/Application Support/com.apple.voicememos/Recordings

# Путь к папке в Obsidian, куда сохранять транскрипции
OBSIDIAN_VAULT_PATH=/Users/viktorivanov/Documents/Obsidian/MyVault/Daily Diary

# Язык транскрипции (ru = русский, en = английский)
TRANSCRIPTION_LANGUAGE=ru

# Извлечение задач из дневника
EXTRACT_TASKS=true
```

### Получение API ключей

**Groq (бесплатно для транскрипции):**
1. Зарегистрируйтесь на https://console.groq.com
2. Перейдите в раздел **API Keys**: https://console.groq.com/keys
3. Создайте новый ключ
4. Скопируйте и вставьте в `.env` как `GROQ_API_KEY`

**OpenRouter (для улучшения текста и задач):**
1. Зарегистрируйтесь на https://openrouter.ai
2. Перейдите в раздел **Keys**: https://openrouter.ai/keys
3. Создайте новый ключ
4. Скопируйте и вставьте в `.env` как `OPENROUTER_API_KEY`
5. Пополните баланс (от $5) на https://openrouter.ai/credits

### 5. Проверьте путь к Voice Memos

Убедитесь, что папка с записями существует:

```bash
ls -la ~/Library/Application\ Support/com.apple.voicememos/Recordings/
```

Если папка не существует:
- Запустите приложение "Диктофон" на Mac
- Сделайте тестовую запись
- Проверьте снова

## 📖 Использование

### Запуск в обычном режиме

```bash
python voice_memo_watcher.py
```

При первом запуске скрипт:
1. Обработает все существующие записи
2. Начнет отслеживать новые записи

### Что происходит при работе

1. **Обнаружение:** Скрипт обнаруживает новый `.m4a` файл в папке Voice Memos
2. **Транскрипция:** Отправляет его в OpenAI Whisper для расшифровки
3. **Сохранение:** Создает заметку в Obsidian в формате:

```markdown
# 2024-11-15 - Voice Memo

**Дата записи:** 15.11.2024 14:30
**Источник:** My Recording.m4a

---

[Текст транскрипции]

---

*Автоматически транскрибировано: 15.11.2024 14:35*
```

### Логи

Все события записываются в:
- Консоль (stdout)
- Файл `voice_memo_watcher.log`

### Остановка

Нажмите `Ctrl+C` для остановки мониторинга.

### 📦 Обработка больших файлов

Groq Whisper API имеет ограничение на размер файла в 25 MB. Скрипт автоматически:

- **Обнаруживает** файлы размером более 20 MB
- **Разделяет** их на части оптимального размера
- **Транскрибирует** каждую часть отдельно
- **Объединяет** результаты в единый текст

Это позволяет обрабатывать записи любой длительности без ограничений!

## 🛠️ Устранение проблем

### Папка Voice Memos не найдена

Если скрипт не может найти папку с записями:

1. Проверьте, что Voice Memos установлен и работает
2. Сделайте тестовую запись
3. Поищите файлы вручную:

```bash
find ~/Library -name "*.m4a" -type f 2>/dev/null | grep -i voice
```

### Проблемы с доступом к файлам

macOS может потребовать предоставить доступ к файлам:
- Откройте **Системные настройки** → **Конфиденциальность и безопасность** → **Полный доступ к диску**
- Добавьте Terminal (или приложение, из которого запускаете скрипт)

### API ключ не работает

1. Проверьте, что ключ правильно скопирован в `.env`
2. Убедитесь, что у вас есть кредиты на аккаунте OpenRouter
3. Проверьте на https://openrouter.ai/credits
4. Убедитесь, что модель поддерживает аудио: https://openrouter.ai/models

### Записи не появляются в Obsidian

1. Проверьте путь `OBSIDIAN_VAULT_PATH` в `.env`
2. Убедитесь, что у скрипта есть права на запись в эту папку
3. Проверьте логи в `voice_memo_watcher.log`

## 📋 Автоматическое извлечение задач из дневника

Система автоматически анализирует ваши голосовые заметки и извлекает из них задачи и напоминания. Все задачи собираются в единый файл, организованный по месяцам и дням.

### Как это работает

При обработке каждой голосовой записи система:
1. **Анализирует текст** и ищет задачи, дела, напоминания
2. **Извлекает конкретные действия** (например: "позвонить Оксане", "купить продукты")
3. **Выделяет важные напоминания** (например: "встреча с психологом 15 числа в 14:00")
4. **Добавляет в единый файл** с автоматической организацией по датам

### Структура файла задач

Файл `Задачи из дневника.md` организован следующим образом:

```markdown
# Задачи и напоминания из дневника

## Ноябрь 2024

### 18 ноября, понедельник

*Из заметки: Планы на неделю*

#### Задачи
- [ ] Позвонить Оксане в пятницу
- [ ] Купить продукты для ужина
- [ ] Отправить отчет до конца недели

#### Важное
- Встреча с психологом 20 ноября в 14:00
- День рождения Юли 25 числа

---

### 19 ноября, вторник

...
```

### Настройка

В `.env` файле:

```bash
# Включить/выключить извлечение задач
EXTRACT_TASKS=true

# Путь к файлу с задачами
# Можно указать путь внутри Obsidian для удобства
TASKS_FILE_PATH=Задачи из дневника.md
# Или:
# TASKS_FILE_PATH=/Users/viktorivanov/Documents/Obsidian/MyVault/Задачи из дневника.md
```

### Преимущества

- **Не забывайте важное**: Все задачи из устных заметок автоматически фиксируются
- **Единое место**: Все дела и напоминания в одном файле
- **Хронология**: Организация по месяцам и дням помогает понять контекст
- **Чекбоксы**: Markdown чекбоксы `- [ ]` работают в Obsidian и других редакторах
- **Ссылки на заметки**: Указание источника для быстрого доступа к полной записи

### Отключение функции

Если вам не нужно извлечение задач, просто установите в `.env`:

```bash
EXTRACT_TASKS=false
```

## 🧠 Глубинный самоанализ дневниковых записей

Система автоматически проводит глубинный анализ ваших дневниковых записей по 4 ключевым блокам внутренней работы. Это помогает в самопознании, рефлексии и личностном росте.

### Как это работает

При обработке каждой записи система:
1. **Анализирует текст** бережно и без оценок
2. **Проводит рефлексию** по 4 блокам
3. **Создает честный самоанализ** от первого лица
4. **Сохраняет в единый файл** с организацией по датам

### 4 блока анализа

#### 1. Благодарность и достижения
- За что я благодарен сегодня?
- С чем я справился? (даже маленькие шаги)
- Что приятного я сделал для себя?

#### 2. Эмоции и тело
- Какое чувство или мысль меня зовёт?
- Что это чувство хочет мне сказать?
- Как оно ощущается в теле? (метафора: цвет, текстура, вес)

#### 3. Смысл и будущее
- Что сделало бы сегодняшний день по-настоящему стоящим?
- На что я трачу время впустую?
- Что меня вдохновляет в будущем?

#### 4. Вызовы и рост
- Какое сложное действие я откладываю?
- Какой внутренний "монстр" или страх мешает?
- Что бы сказал мне мудрый я в 90 лет?

### Структура файла рефлексии

Файл `Самоанализ дневника.md` организован следующим образом:

```markdown
# Самоанализ и рефлексия

## Ноябрь 2024

### 18 ноября, понедельник

*Из заметки: Планы на неделю*

#### 1. Благодарность и достижения
Я благодарен за возможность работать из дома и самостоятельно планировать день. Справился с откладываемым звонком клиенту — оказалось не так страшно, как думал. Приятное для себя: вечерняя прогулка в парке помогла разгрузить голову.

#### 2. Эмоции и тело
Чувство тревоги по поводу завтрашней встречи. Оно хочет сказать, что я хочу показаться с лучшей стороны, боюсь осуждения. В теле — как сжатый комок в груди, серого цвета, тяжёлый и плотный.

#### 3. Смысл и будущее
День стал бы по-настоящему стоящим, если бы я поработал над проектом, который откладываю. Трачу время впустую на бесконечную прокрутку новостей — это не приносит ничего ценного. Вдохновляет мысль о поездке в горы на следующей неделе.

#### 4. Вызовы и рост
Откладываю начало нового проекта из-за страха не справиться, показаться некомпетентным (мой "монстр перфекционизма"). Мудрый я в 90 лет сказал бы: начни с малого, сделай хотя бы один шаг — опыт важнее идеального результата.

---
```

### Настройка

В `.env` файле:

```bash
# Включить/выключить глубинный самоанализ
ENABLE_SELF_REFLECTION=true

# Модель для анализа (рекомендуется gpt-4o-mini или claude-3.5-haiku)
SELF_REFLECTION_MODEL=openai/gpt-4o-mini

# Путь к файлу рефлексии
REFLECTION_FILE_PATH=Самоанализ дневника.md
# Или внутри Obsidian:
# REFLECTION_FILE_PATH=/Users/viktorivanov/Documents/Obsidian/MyVault/Самоанализ дневника.md
```

### Преимущества

- **Глубокая рефлексия**: Честный анализ без самообмана и поверхностности
- **Регулярность**: Автоматический анализ каждой записи
- **Хронология**: Возможность отследить динамику внутренней работы
- **Бережность**: Анализ без осуждения, морали и нравоучений
- **Практичность**: Конкретные вопросы и инсайты для личностного роста

### Отключение функции

Если самоанализ вам не нужен, установите в `.env`:

```bash
ENABLE_SELF_REFLECTION=false
```

### Рекомендуемые модели

Для самоанализа лучше использовать более умные модели:

```bash
# GPT-4o Mini (рекомендуется) - хороший баланс
SELF_REFLECTION_MODEL=openai/gpt-4o-mini

# Claude 3.5 Haiku - лучшее качество для рефлексии
SELF_REFLECTION_MODEL=anthropic/claude-3.5-haiku

# Gemini Flash 1.5 - дешевле, но менее глубокий анализ
SELF_REFLECTION_MODEL=google/gemini-flash-1.5
```


#### Модель глубинного самоанализа (OpenRouter)

```bash
# GPT-4o Mini (рекомендуется) - хороший баланс
SELF_REFLECTION_MODEL=openai/gpt-4o-mini

# Claude 3.5 Haiku - лучшее качество для рефлексии
SELF_REFLECTION_MODEL=anthropic/claude-3.5-haiku

# Gemini Flash 1.5 - дешевле, но качество ниже
SELF_REFLECTION_MODEL=google/gemini-flash-1.5

# Бесплатная модель (базовое качество)
SELF_REFLECTION_MODEL=google/gemini-2.0-flash-exp:free
```

Полный список моделей OpenRouter: https://openrouter.ai/models

### Изменение формата заметок

Отредактируйте метод `ObsidianWriter.save_transcription()` в `voice_memo_watcher.py`

### Поддержка других форматов

Скрипт поддерживает: `.m4a`, `.mp3`, `.wav`, `.m4v`, `.aac`, `.ogg`, `.flac`

Для добавления других форматов, измените список в методе `VoiceMemoHandler.on_created()`

### Другие языки

Поддерживаются многие языки. Измените `TRANSCRIPTION_LANGUAGE` в `.env`:
- `ru` - Русский
- `en` - Английский
- `es` - Испанский
- `fr` - Французский
- `de` - Немецкий
- и т.д.
